# Linux 服务器部署清单

开发机(Windows)上的安全机制大多在代码里,部署到 Linux 时**自动生效**;但有一批**环境级配置必须在每台服务器上重新做**,本文按顺序列成清单,照着勾即可。

## 哪些跟代码走(不用重做)

| 机制 | 说明 |
|---|---|
| Argon2id + pepper 版本化密码哈希 | `app/core/security.py`,新环境配上自己的 pepper 即可 |
| 登录/改密 RSA 加密传输 | 公私钥首次启动自动生成到 `backend/rsa_key.pem`(多进程共用,勿提交 git) |
| 连错 5 次锁定 10 分钟 | 库字段 + 登录逻辑 |
| 复杂密码校验、初始密码强制修改 | 前后端双重校验 |
| 菜单/路由权限控制 | 角色-权限-用户体系 |

## 部署步骤(裸机部署)

### 1. 基础环境

- Python 3.10+、Node.js 18+(仅构建时需要)、MySQL 8+、nginx

### 2. 拉代码 + 后端依赖

```bash
git clone <仓库地址> /opt/pysswhl && cd /opt/pysswhl/backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

### 3. 生成全新 .env(不要拷贝开发机的!)

```bash
cp .env.example .env
# 逐项填写,以下三项必须用新随机串:
#   SECRET_KEY=      python -c "import secrets; print(secrets.token_hex(32))"
#   PASSWORD_PEPPER= python -c "import secrets; print(secrets.token_hex(32))"  设好永不更改
#   DB_PASSWORD=     同上,并与下一步 MySQL 保持一致
# 数据库连接保持 127.0.0.1(应用与数据库同机)
```

### 4. MySQL 加固(照搬开发机做法)

- `my.cnf` 的 `[mysqld]` 段加 `bind-address=127.0.0.1`,重启 MySQL
- 不用 root 跑应用:建专用账号并只授权本项目库

```sql
CREATE USER 'sswhl_app'@'localhost' IDENTIFIED BY '<强口令>';
GRANT ALL PRIVILEGES ON sswhl_new.* TO 'sswhl_app'@'localhost';
```

- 建库并初始化:`python -m scripts.init_db`

### 5. 前端构建 + nginx

```bash
cd ../frontend && npm install && npm run build   # 产物在 dist/
```

nginx 要点:`root` 指向 `dist/`;`location /api/ { proxy_pass http://127.0.0.1:8000; }`;前端是 history 路由,需 `try_files $uri $uri/ /index.html;`。正式使用建议配 HTTPS(内网自签证书或单位证书)。

### 6. 后端以服务方式常驻

systemd 单元要点:`ExecStart=/opt/pysswhl/backend/.venv/bin/uvicorn app.main:app --port 8000`;内网几百人规模单进程足够(见下方"注意")。

## 安全清单(逐项确认)

- [ ] `.env` 三个密钥(SECRET_KEY / PASSWORD_PEPPER / DB_PASSWORD)全部为**本机新生成**的随机串
- [ ] `PASSWORD_PEPPER` 设好后永不更改(更改=全体用户无法登录)
- [ ] MySQL 仅监听 127.0.0.1,应用使用专用账号,root 强口令
- [ ] 防火墙只对内网开放 80/443,**3306 与 8000 不对外**
- [ ] `backend/.env` 与 `backend/rsa_key.pem` 权限 600,纳入服务器备份但**不进 git**
- [ ] 服务器时间正确(JWT 过期判断依赖时间)

## 备份

- 数据库:`mysqldump` 定时任务(cron),备份文件放数据库之外的盘/机
- `backend/.env` 与 `rsa_key.pem`:单独备份;**pepper 丢失 = 全体用户无法登录**(可重置密码应急,但要知道自己在做什么)

## 注意事项

- **多 worker**:uvicorn `--workers N` 已支持(RSA 密钥落盘共享);要加 worker 直接加即可
- **时区**:JWT 与各时间字段用服务器本地时间,保持系统时区为 Asia/Shanghai 即可
- **INITIAL_PASSWORD**:部署后建议立刻改掉默认值 abc123456(改 `.env` 后重启后端)
- Docker 方式(compose: api + mysql + nginx)以后按需补,代码无需改动
