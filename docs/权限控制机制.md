# 用户访问权限控制机制

新模块开发时,用户能不能访问某个功能,由一套现成的权限链路控制。本文说明这套机制的原理和新模块的接入方法。

## 机制概览:三层结构

### 1. 数据层(权限从哪来)

- 权限是一条条**权限码**,如 `system:user:manage`,存在 `permissions` 表。
- 权限码挂在**角色**上(多对多),用户通过被分配的角色获得权限。
- `admin` 是超级管理员(`is_superuser=True`),**天然拥有所有权限**,不需要勾选。
- 全部权限码在 `backend/scripts/init_db.py` 的 `DEFAULT_PERMISSIONS` 里登记,重跑 init_db 时自动补进数据库。

现有权限码:

| 权限码 | 含义 | 控制页面 |
|---|---|---|
| `system:user:manage` | 用户管理 | /system/users |
| `system:dept:manage` | 部门管理 | /system/depts |
| `system:role:manage` | 角色权限管理 | /system/roles |

### 2. 后端校验(真正的安全防线)

`backend/app/api/deps.py` 提供两个依赖:

- `Depends(get_current_user)` —— 只要求登录(校验 JWT、账号未停用);
- `Depends(require_permission("权限码"))` —— 超管直接放行;否则检查用户角色是否挂有该权限码,没有返回 403。

接口上加一行依赖即完成控制:

```python
@router.post("")
def create_vehicle(
    data: VehicleIn,
    db: Session = Depends(get_db),
    _user: User = Depends(require_permission("vehicle:manage")),  # ← 权限控制就这一行
):
```

**后端校验是权限的真正落点。** 前端隐藏菜单只是为了不让用户看到进不去的入口;任何绕过前端的请求,最终都靠后端 403 挡住。新接口无论多简单,必须挂后端校验。

### 3. 前端控制(体验引导,不是安全)

- **菜单**:`src/layout/MainLayout.vue` 的 `menuItems` 里用 `auth.hasPerm('权限码')` 决定菜单项是否出现;
- **路由**:`src/router/index.js` 路由的 `meta.perm` 配权限码,守卫里没权限访问会被踢回 `/dashboard`;
- **按钮级**:页面内用 `v-if="auth.hasPerm('xxx:yyy')"` 控制按钮显示。

用户权限来自登录/`/auth/me` 接口返回的 `permissions` 数组,存在 Pinia(`src/stores/auth.js`)。给用户换了角色后,重新登录或刷新页面生效。

## 新模块接入模板(以"车辆管理"为例)

1. **登记权限码**:`DEFAULT_PERMISSIONS` 加 `("vehicle:manage", "车辆管理")`,重跑 `python -m scripts.init_db`(幂等,只补缺的)。不登记的话,「角色权限」页面的勾选列表里看不到它。
2. **后端路由**:`app/api/routes/vehicle.py`,增删改接口挂 `require_permission("vehicle:manage")`;只要求登录的读接口(如下拉数据)用 `get_current_user`;在 `main.py` 里 `include_router`。
3. **前端页面**:`src/api/vehicle.js` 封装接口,`src/views/vehicle/VehicleManage.vue` 写页面。
4. **挂路由和菜单**:`router/index.js` 加路由并带 `meta: { perm: 'vehicle:manage' }`;`MainLayout.vue` 的 `menuItems` 加一行 `if (auth.hasPerm('vehicle:manage')) vehicles.push(...)`。
5. **授权**:管理员在「角色权限」页面把"车辆管理"勾给某个角色,再把角色分配给用户。对应用户重新登录(或刷新页面)后即可看到菜单。

## 粒度约定

- 当前统一用 `模块:manage` 的**页面级粗粒度**,够用且好维护。
- 某模块需要细分时(如"车辆管理"里导出报表单独控制),再加 `vehicle:export` 这类权限码:前端按钮 `v-if="auth.hasPerm('vehicle:export')"` 隐藏,后端对应接口同样挂 `require_permission`。**权限码先在 DEFAULT_PERMISSIONS 登记**,套路同上。
- 命名统一为 `模块:动作`,全小写英文,冒号分隔。
