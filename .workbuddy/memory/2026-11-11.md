## 左侧菜单行高紧凑化（MainLayout.vue）
- 需求：「主页菜单项高度可以紧凑点」→ 全局左侧菜单，非首页内容。
- Element Plus 2.14.7 默认高度来自 `:root` 变量：`--el-menu-item-height:56px`、`.el-sub-menu .el-menu-item` 用 `--el-menu-sub-item-height:calc(item-6px)=50px`；height 与 line-height 同用变量，另有折叠动画，写死 height 会破坏居中。
- 实现：`.menu` 上覆盖 `--el-menu-item-height:40px`、`--el-menu-sub-item-height:34px`，`.el-menu--inline` 上下 padding 4px→2px；缩进变量、圆点、选中态、颜色全部不动。`.logo`/`.header` 仍 60px。
- `backend/scripts/ui_check_finance_cdp.js` 增 `menuHeights`（top/sub 实测高度 + 子项数）与 gdzc 页侧栏 220×740 局部截图 `ui_layout_menu.png`，作为长期回归基线。
- 验证：`npm run build` 通过；CDP 三页实测 top=[40]、sub=[34]（43 子项），0 JS 异常、页面无滚动条；既有回归项不退化（22 列表头、工具栏按钮 32px 同行、wzcgsq ↓ 续行）。截图目视：图标/文字垂直居中、圆点与文字对齐、选中高亮条完整、无截断重叠。
